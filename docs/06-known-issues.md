# 06 · 已知限制

1. **镜像是基础版，不含 2026-11-07 的两项修复。**
   `update.img` 打包于 2026-11-06 19:27；竖屏与 ArkWeb 修复是之后在板上完成的。必须按 [02](02-apply-patches.md) 应用补丁，才能得到演示机的状态。

2. **整镜像尚未重新打包。**
   没有把补丁烤进 `update.img`，因此不存在“刷完即用”的单文件镜像。重打包流程未在本项目验证，见 [05](05-build.md)。

3. **补丁是开发方式，不是 OTA。**
   直接 `dd` 启动分区、替换 `/system` 下的 `.so`，依赖 root shell 和可写挂载。适合开发、评测与复现，不适合量产或不可信环境。

4. **Wi-Fi 未单独复测。**
   内核替换时同步更新了 4 个 rtw89 模块并保留原件，但换内核后没有单独做联网回归。若 Wi-Fi 异常，先回退模块再排查。

5. **只适用于这块板与这套屏参。**
   竖屏补丁包含 `display_manager_config.xml` 与显示/窗口服务的本地修改；换载板、换屏或换分辨率需要重新适配，不能直接套用。

6. **触摸未接入。**
   实机使用 USB 鼠标操作；输入坐标按 1080×1920 逻辑分辨率验证。

7. **第三方二进制。**
   镜像内含 Rockchip / Orange Pi 的固件、GPU 驱动、Wi-Fi 固件等二进制，权利归各自所有者，按原许可随镜像分发；本仓库不授予额外许可。

8. **非官方镜像。**
   本项目是学生竞赛作品的板级适配产物，与 OpenHarmony 社区、Orange Pi 官方无隶属关系，不提供官方支持。
